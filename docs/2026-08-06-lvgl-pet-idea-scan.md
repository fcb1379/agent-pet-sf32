## 选择理由与否决条件

Agent Quest Garden 使用仓库独有的 Agent 快照作为“环境”，并只在任务首次进入 `COMPLETED` 时生成成长事件。用户看到新芽，点击收下该次成果，花园获得一片叶；当日进度和连续有成果天数被持久化。它不创造虚假的远端操作，也不读取任务正文。

进入开发的硬条件：

- 方案必须证明同一任务的重复快照不会重复计数。
- 断线、乱序、设备重启和日期变化均有确定行为。
- 点击只确认本地奖励，不得被描述成批准、完成或控制远端任务。
- 不新增外部素材；首版只用 LVGL 基本对象、现有宠物图和现有字体。
- PC 模拟器必须能注入完成、重复、错误、断线和跨日序列。

若上述任一条件无法以小改动满足，应回退为“只显示今日完成次数”的只读最小版本，或停止开发。
